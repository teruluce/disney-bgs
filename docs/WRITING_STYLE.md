# BGS Chronicles 文体ルール（全AI共通）

更新日：2026-11-24

## 1. 位置づけ

新規執筆・増補・改稿・校正を行うすべてのAIに適用する文体の正本。運営憲章および編集基準の事実・出典・デザイン・公開の規定を変更するものではない。物語世界の扱いと不確実性については [EDITORIAL_STANDARDS.md](../EDITORIAL_STANDARDS.md#in-world-narration--owners-rule-2026-10-30) に従う。運営者の承認済み原稿を優先する。

## 2. 手本記事

- 第一基準：[アメリカンウォーターフロント](../bgs-americanwaterfront.html) の冒頭・第I章。歴史紀行・文化誌・新聞の特集記事として、具体的な情景から歴史と暮らしへつなぐ。
- 記録・事件型：[タワー・オブ・テラー](../bgs-tot.html)。
- おとぎ話・世界旅行型：[ファンタジースプリングス](../bgs-fs.html)（S10）。
- 補助基準：[ホテルミラコスタ](../bgs-miracosta.html)。場面同士のつなぎ方や余韻を参考にする。直接的な案内口調は新しい原則に従い抑える。

新規執筆・改稿では題材に近い手本を読み、口調と描写の水準を合わせる。定型句や構成をそのまま模倣しない。部分校正のみの依頼では担当AIから共有された必要部分と抜粋で足りる。利用枠を節約するため、ChatGPT等が事前に規則を確認し、Claudeには校正対象と必要な文体規定だけを渡してよい。

### 第一基準の抜粋（運営者指定）

> アメリカンウォーターフロントには、異なる時間の流れを感じさせる二つの町があります。ひとつは、大西洋を行き来する客船と、世界中から訪れた人々でにぎわうニューヨーク。もうひとつは、ニューイングランドの海辺に広がる漁村ケープコッドです。
>
> ニューヨークでは、建物が道に沿って高く立ち並びます。劇場の看板は遠くからでも目に入り、路面には線路が埋め込まれ、鉄骨の高架橋が通りを横切っています。岸壁へ近づけば、倉庫や船会社の建物、荷を運ぶための設備が集まっています。船から降りた品物が、ここから街の店や鉄道へ運ばれていくのでしょう。
>
> 一方、ケープコッドの道は低い木造の家々のあいだを通り、海へ向かって緩やかに開けています。通りの看板には魚や船の姿が描かれ、家々の庭には手仕事の気配が残っています。大都市のように新しい建物が次々と建つ場所ではなく、住民が顔を知る町です。
>
> 両者を結ぶのは海だけではありません。ニューヨークの港で始まる商いも、ケープコッドの小舟が支える暮らしも、水辺の仕事から生まれました。アメリカンウォーターフロントを歩くことは、同じ時代を生きる人々が、どのように異なる未来へ向かおうとしていたのかを見ることでもあります。

### 補助基準の抜粋（従来の運営者校正原稿）

> ミラコスタのロビーに入ると、まず吹き抜けの空間の中央に大きなガリオン船が見えてきます。帆を張った船の甲板には、船長のミッキーとその仲間たちがいます。船のそばから天井を見上げてみると、八角形の天井を囲むように8枚の絵が並んでいるのが見えるでしょう。
>
> そのうち7枚に描かれているのは、開園当初の七つの港です。一枚ずつ見ていくと、背景の街並みや水辺の風景から、旅の記憶がよみがえります。残る8枚目には、まだ知らない海へ向かう者たちの「発見の精神」が描かれています。
>
> ロビーのガリオン船は、カピターノ・ミッキー・スーペリアルームでも姿を確認することができます。壁の絵を眺めていると、先ほどはロビーにいた船が海の上を進んでいます。その部屋には航海図があり、天井には仲間たちの姿をかたどった星座が描かれています。窓辺から離れても、部屋の中にはまだ見知らぬ世界への航海の続きが残っているのです。

## 3. 基本の語り方

- 案内するのではなく描写する。情景、具体物、年・場所・人物など、根拠のある細部から始め、歴史や人々の暮らしへ自然につなげる。すべての章を同じ型で始める必要はない。
- 語り手を前に出さない。読者自身が世界を歩いている感覚を保つ。事実や情景で伝わる感情・評価を説明し直さない。
- 確認できた出来事はその世界の歴史として語る。物証や人物の視点を用いる場合は裏付けのあるものに限り、観察・心情・台詞を創作しない。
- 確認済みの制作理念を単なる感想や推測に弱めない。根拠のない意図は断定しない。不確実な点の扱いは編集基準に従う。
- 同じ場面・論点を一段落にまとめ、文の長さや視点の移り変わりで流れをつくる。段落や章をまたぐ単なる言い換えを避ける。
- 締めは具体的な光景、事実、対比、記事固有の主題などで余韻を残す。内容のない感傷や一般論の教訓は避ける。確認された理念を伝える結びは妨げない。

## 4. 文末とリズム

- 落ち着いた自然な「です・ます」調。現在の情景は現在形、歴史上の出来事は過去形を基本とし、文脈に合わせる。効果的な体言止めも許容する。
- 「〜のです」「〜なのです」は驚き、転換、核心の一文などに限定し、連続・多用を避ける。数か所程度を目安とするが、記事の長さに応じて判断する。
- 同じ文末や段落の締めが3回以上続く場合は見直す。ただし自然な文章を無理に変えない。描写、短い断片、対比、事実、必要な問いなどでリズムをつくる。
- 逆接は「しかし」「一方で」「ただし」などの落ち着いた書き言葉を優先する。「ただ、」等も文脈上自然なら許容し、機械的に置換しない。
- 「〜に目を留めたくなります」「〜が見えてきます」を段落の締めとして繰り返さない。不自然な助詞、係り受け、主語・述語、語順、翻訳調の日本語を見直す。不必要な受動表現・修飾語・読点を減らし、堅い専門語より自然で親しみやすい日本語を選ぶ。「ここは〜」「こうして〜」などの語りや、情景に根差した文学的表現は効果的なら使う。

## 5. 呼びかけ・案内口調

案内役が前面に出る「さあ、〜しましょう」「それでは、出発しましょう」「ご案内します」「ご覧ください」「想像してみてください」「ご乗船、ありがとうございました」は原則使用しない。「注目してみましょう」「探してみてください」は原則として描写に置き換える。ただし「注目してみると」「よく見ると」のように観察を自然につなぐ表現は、題材に合い、反復しなければ許容する。

「耳を澄ませれば〜」「〜を見つけられるでしょうか」等の軽い誘いは記事の雰囲気に合う場合のみ許容。多くても1章に1回程度を目安とし、使う必要がなければ使わない。疑問文や読者の視線の移動を一律に禁止するものではない。

## 6. 記事の性格に応じた調整

全記事で統一するのは日本語の品質、編集思想、事実の扱いであり、語り口そのものではない。以下の5分類から題材に合う主文体を選び、必要に応じて副文体を組み合わせる。アメリカンウォーターフロントは共通の品質基準だが、全記事をその語り口に揃える必要はない。

| 文体 | 手本・題材例 | 調子 |
|---|---|---|
| 歴史記録・事件型 | タワー・オブ・テラー、インディ・ジョーンズ、S.E.A. | 重厚で静かな語り。裏付けのある年代・人物・事件・記録を積み重ね、緊張感や謎を残す。真相不明という設定と調査不足を混同しない。 |
| 歴史紀行・文化型 | アメリカンウォーターフロント、ワールドバザール、ウエスタンランド | 街並み・建築・道具・交通・仕事・暮らしから時代背景へつなぐ。歴史雑誌の特集記事のように語る。 |
| 物語・昔話型 | スプラッシュ・マウンテン、美女と野獣、シンドバッド | 親しみやすい語り。登場人物の行動、出来事の原因と結果、その後の暮らしを中心に物語を進める。 |
| 幻想・情景型 | ファンタジースプリングス、ホテルミラコスタ | 穏やかなリズム。水・光・音・建築など具体的な情景に根差した比喩や軽い誘いを適度に許容する。 |
| 制作史・理念型 | イッツ・ア・スモールワールド、エレクトリカルパレード、東京ディズニーシー誕生史 | イマジニアの仕事・制作過程・理念を親しみやすく説明する。確認済みの理念は率直に伝え、物や場面と結びつける。年号や抽象語の羅列、同じ結論の反復を避ける。 |

### 執筆前の文体設定

新規執筆・大幅改稿の前に、主文体、副文体（必要な場合）、重厚感、親しみやすさ、文学的表現の程度、歴史情報の比重、読者への呼びかけ、理念の説明方針を短く定める。引き継ぎにも必要な設定を含める。部分校正では既存の文体を尊重し、新たな文体設定による全面改稿を行わない。

例：スモールワールドは主文体＝制作史・理念型、副文体＝幻想・情景型、重厚感＝中、親しみやすさ＝高、文学的表現＝適度、歴史情報＝多め、呼びかけ＝少なめ、理念＝明確かつ率直。制作史の章と水路の情景の章では語り口を変えてよい。ただし章の境目で唐突に調子を変えず、記事全体の自然な流れを保つ。

分類や設定は編集上の目安であり、固定テンプレートや数値ノルマではない。題材によって柔軟に組み合わせる。運営者の確定原稿を変更する根拠にはしない。

運営者自身の添削例と文体上の判断は [WRITING_EXAMPLES.md](WRITING_EXAMPLES.md) を参照する。

## 7. 避ける表現と正確性

SNS調、煽り、説教調、報告書調、Wikipedia調、過剰な詩的表現、過剰な比喩、抽象語の反復、感動の押し付けを避ける。出典・調査に関するメタ発言、世界観を壊す表現、創作、事実と推測の扱いは [編集基準の該当規定](../EDITORIAL_STANDARDS.md#editorial-voice-and-uncertainty) を参照する。イマジニアの制作説明という例外は同基準の範囲内に限る。

## 8. 添削例

- 案内調：「さあ、乗船しましょう。ボートがゆっくりと水路を進むと、〜」→「ボートがゆっくりと水路を進むと、岸辺から子供たちの歌が聞こえてきます。」
- 促す言い方：「ボートの乗り場で足元に目を向けてみてください。そこには、子供たちが捕まえた星の影が落ちています。」→「ボートの乗り場の足元には、子供たちが捕まえた星の影が落ちています。」
- 核心の一文：「世界の国々を巡るこの船旅には、誕生当初から平和への願いが込められているのです。」（「のです」をここぞという箇所に使う。）
- 軽い誘いの例：「耳を澄ませれば『川の向こうで』の旋律が聞こえ、歌と水の動きがひとつの風景をつくっています。」

## 9. 校正・既存記事の修正

- 依頼範囲内の小さな添削を優先し、既存の個性・情報量・構成・見出し・デザインを尊重する。増補や構成変更は明示的な依頼がある場合に限る。
- 増補改訂では現行の内容・分量を維持するか、依頼に沿って増やす。重心を変えるために無断で削らない。
- Claudeを部分校正に用いるときは、原則として不自然な日本語の修正箇所だけを返す。調査・全面改稿・リポジトリ確認は別途依頼された場合に限る。
- 運営者が最終確定原稿を指定した場合、実装時に一字一句変更しない。表示に必要なマークアップやエスケープのみ許容する。疑義は別に報告し、修正は承認後に行う。確定稿への変更は単に記録するだけでは足りない。

## 10. 完成時チェック

- [ ] 題材に合う主文体・副文体になっているか（新規執筆・大幅改稿）
- [ ] 案内役の宣言や促す言い方が過剰でないか
- [ ] 軽い誘いは記事に必要で、頻度が適切か
- [ ] 文末・段落の締め・「のです」が単調に反復していないか
- [ ] 日本語が自然で、時制・助詞・係り受けが正しいか
- [ ] 具体的な建物・道具・人物・風景などから語れているか
- [ ] 事実・制作理念・不確実性・出典の扱いが編集基準に沿っているか
- [ ] 校正・実装で情報量、構成、見出し、確定原稿を無断で変更していないか
