# X共有文の編集

担当: **Codex-BGS-20261027**

X共有ボタンは `share-captions.json` の記事別紹介文とハッシュタグから生成する。タイトルの転載だけでなく、記事で読める具体的な物語・手がかりを短く紹介する。本文にない新設定や「衝撃の真実」「完全解説」などの過剰な表現、投稿者がまだ読んでいない可能性のある「読んだ」「感動した」は使わない。

各ページは6タグ。広い話題の「ディズニー」、パーク名、施設名または記事テーマ、BGS、ファン交流用、サイト名を組み合わせる。関連のない流行タグは足さない。タグの数や共有文だけで拡散を保証するものではない。

## 編集と反映

1. `share-captions.json` の該当ページの `caption` と `hashtags` を編集する。タグには `#` を含めない。
2. `python scripts/update_share_links.py` でHTMLの共有リンクへ反映する。
3. `python scripts/update_share_links.py --check` とSEO監査を実行する。
4. PRでは設定ファイルの日本語をレビューする。HTMLの長いURLは自動生成結果。

新しい記事に共有ボタンを付けたときも設定を追加する。設定と共有ボタンのあるページ一覧が一致しなければチェックは失敗する。タグは4〜6個、重複なし。今回の文面は日本語・ASCIIだけを使い、非ASCIIを一律2文字として保守的に数える。URL用に24文字分を確保し、合計280文字以内にする。将来emojiや本文内URLを使う場合は文字数検査も対応させる。

完成済みのリンクをHTMLに置くため、JavaScriptが無効でもキャプション・タグ・記事URLが入る。古い記事ごとのJS上書きは撤去済み。Xへの実際の投稿は利用者が投稿画面で確認・編集して行う。
