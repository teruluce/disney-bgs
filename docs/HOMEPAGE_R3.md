## Phase 2-4の問題への対応

1. **カードのフォーカス消失：** グリッドの外側クリッピングを維持し、枠をカード内側に描く。写真のfilterによる描画層にも隠れないよう、フォーカス時の疑似要素で枠を重ねる。マウスhoverの動作と最終行の斜線背景は維持。強制カラーでも確認した。
2. **プロフィールとの枠干渉：** 上部リンクのフォーカス枠を内側にする。操作領域を縮めず、余白追加による写真位置の変化を避ける。
3. **900／901pxの非連続な変化：** 1200px以上の横長PCでは、R3の圧縮配置を画面高によらず適用。900px以下の検討済みR3の配置を保持し、901px以上で大きい題字・不均等な列へ突然切り替わる挙動をなくした。この品質修正により、高いPC画面でも均等な2列と同じ写真枠を使う。縦向きタブレットは従来の縦積みを保持。700px以下のプロフィール右上配置は既存の適応動作として維持。
4. **dateline末尾の省略：** 小さな欧文ラベルを折り返せるようにした。狭幅・フォント未取得時には上部が1行分高くなるが、文字は消えない。390pxと320pxでも写真全体が初画面内に収まる。
